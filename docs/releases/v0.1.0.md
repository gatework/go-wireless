# v0.1.0

Go Wireless 首个正式版本，提供无线控制器证据采集、离线解析、报告复核与交互式受控变更。

- 提供 `wireless collect`、`parse`、`review`、`apply`；核心 Go 库可独立离线使用，无需 Ruby 运行时。
- H3C 支持 AP、radio、BSS、client、配置及 AP LLDP 等维度；Huawei 支持 AP 和 client。未知、截断或不完整证据明确保留 partial/failed。
- 固定使用正式 go-net-connector v0.3.0 与 go-expect v0.4.0。借用操作持有租约，失败 Attempt 原始字节和已接受 Steps 分离，禁止隐式重连与命令重放。
- ChangePlan 深度拥有已验证的 schema 1 计划，保留 Ruby canonical JSON 与完整配置指纹。变更要求真实 TTY 和精确文件确认，按 intent→发送→acknowledgement→读回→清理→最终发布执行。
- 使用平铺的共享 net-connector.yml 和无线专用 wireless.yml；SSH 默认严格主机校验，缓存按非秘密账号身份隔离。

发行包覆盖 Linux/macOS × amd64/arm64，附同提交源码、版本与提交身份、第三方许可、MANIFEST.json 和 SHA256SUMS。macOS 发行二进制由 Go 1.27 构建，要求 macOS 13+；源码最低 Go 1.26.0。

证据完整或配置读回成功不等于业务验收，也不代表配置已保存。没有自动重试、回滚或保存；本次发布验证使用离线资料、注入会话、本地 HTTP/PTY 和 CI，未连接真实控制器或外部库存服务。
