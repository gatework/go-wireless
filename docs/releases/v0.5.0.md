# v0.5.0

本版本引入类型化 WLAN 模型与统一评估、变更接口；旧调用者需要迁移，模块路径保持 `github.com/gatework/go-wireless`。

- `wlan.Controller`、`wlan.Configuration` 与覆盖状态承载业务事实；未知字段会降低证据完整性，不能据此得出健康结论。
- `rules` 通过 go-netops v0.3.0 评估控制器及跨批次漂移，替代旧 `review` 推荐接口。报告使用 assessment 与类型化变更计划。
- `change.TemplateSecurity` 使用类型化配置验证前置条件和回读结果；计划仍绑定配置指纹、目标与精确命令，下发须逐项确认，不自动重放或回退。
- `NewObservation` 改用 `ObservationOptions`，`NewSnapshot` 改用 `SnapshotOptions`；见核心 API 文档。删除旧 Ruby fpconv 指纹兼容路径，新的指纹契约见核心 API 与兼容说明。
- 指纹 UTF-8 预检拒绝循环 map、slice 与指针，避免循环输入导致栈溢出；非循环共享对象仍可使用。
- 开发检查接入 go-standards v1.0.2：共享 lint、架构边界与 `make check`。
- 运行依赖固定正式 go-net-connector v0.7.1、go-expect v0.6.0、go-netops v0.3.0，适配平台声明、配置加载与类型化清单缓存 API。旧缓存身份需要刷新。

要求 Go 1.26 或以上。测试使用冻结语料、模拟连接及独立消费者；不代表真实控制器验收。
