# v0.6.0

本版本升级正式依赖 net-connector v0.9.0、go-expect v0.6.0 与 go-netops v0.4.0；共享清单配置需要迁移。

- 同步更新 pgx v5.13.0、x/term v0.48.0 和 x/text v0.44.0，最低 Go 版本保持 1.26.0。
- 清单筛选改为 `include_platforms` / `exclude_platforms`，平台覆盖改为 `platform_overrides`，`device_rules[].connector` 改为 `device_rules[].platform`；对应环境变量改用 `PLATFORM`。
- 共享 SSH 配置中的 `vendor_protocols` 改为 `platform_protocols`；Wireless 仍只继承主机信任设置，控制器连接使用 SSH。
- 注册表接口改用 `net-connector/platform.Registry`，清单解析使用 `Record.Platform`；原始 Netdisco `Device.Vendor` 字段保留。
- 控制器和 AP 查询仍受选定 profile 约束，已接受回执与后置清理错误分别保留，不自动重放、重连、回滚或保存配置。

最低 Go 版本保持 1.26。模拟会话、冻结语料和独立消费者验证不代表真实控制器验收。
