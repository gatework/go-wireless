# v0.2.0

本版本按业务能力重整代码，包含不兼容的公开 Go 包路径变更。CLI 参数、退出码、配置优先级、证据 JSON、精确数值和变更计划指纹保留既有约定。

- 根包保留证据值；解析契约在 parser，H3C/Huawei 实现在 vendors，采集、诊断、变更分别归 collect/review/change，适配器迁至 adapter/netconnector。
- cli 已内部化；Cobra、Bootstrap 装配和 Workflow 编排分工明确。库调用方应迁移到公开业务包，不再导入 CLI 应用实现。
- 厂商声明和 Profile 取得独立所有权，拒绝零值 Profile；AP LLDP 解析使用选定 Profile，保留 AP 名称、模型与不完整证据规则。
- 父 context 取消后停止接纳后续写入，即使借用操作 context 被注入方分离；已经确认的步骤、清理错误和检查点继续保留。
- 固定正式 Connector v0.4.0、Expect v0.4.1，复用共享清单采集及环境/配置规则。清单缓存升级后先按新身份刷新，再使用 cache-only。

导入路径及数据所有权见 [核心 API](../core-api.md)、[传输 API](../transport-api.md) 和 [CLI 约定](../cli-api.md)。人工建议不会直接成为可执行计划；仍需真实终端确认、指纹绑定和配置前后核验。

发行包覆盖 Linux/macOS × amd64/arm64，附同提交源码、版本与提交身份、完整许可、MANIFEST.json 和 SHA256SUMS。发布复用同提交 CI 制品；未以模拟会话或 CI 结果宣称真实设备或生产验收。
