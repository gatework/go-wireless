# v0.6.1

统一构建入口继续使用项目内 Makefile，并默认运行已发布的 go-standards v1.1.0。移除对相邻 go-standards 目录的自动选择，避免本地规范版本与仓库内副本不一致时导致 make check 失败。共享 .golangci.yml 与 standard.mk 由正式 stdsync v1.1.0 重新分发。

直接在仓库根目录执行 `make check`；CI 执行相同入口。规范开发者仍可显式设置 `STANDARDS_DIR`，但该 checkout 的版本必须与仓库内规范副本一致。

此补丁不改变库的公共 API 或控制器行为；v0.6.0 的迁移说明仍适用。
