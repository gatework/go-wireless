# v0.3.0

本版本将查询声明贯通真实控制器和 AP 执行，包含公开 Go API 调整；CLI 参数、证据 JSON、精确数值、来源顺序与指纹保留。

- `netconnector.Borrow/Open` 和 `NewAPSession` 显式接收选定 Profile；`APReader.Read` 改为接收带 AP 身份和 APQuery 的 `collect.APRequest`。适配器在连接或写入前拒绝不匹配能力，不再反复构建内置目录。
- AP 查询与准备命令来自 Profile。启用 APNeighbors 的 ProfileSpec 需声明 APPreparation 及独立 LLDP 查询；原 collect.LLDPCommand 改为 APQuery.Command()。H3C 会话、身份验证与退出规则保持，未扩展 Huawei AP 能力。
- 适配器共用 Connector 接受回执和严格正文；Wireless 失败 Capture 仍不提供成功 Body，提示符换行与原始 Attempts 契约保持。
- 配置和环境加载传播 context、复用 16 MiB 有界读取；报告证据保持独立容量规则。运行设置冻结，apply 使用私有类型化状态和独立日志投影，通过小接口识别发布提交。
- 证据复制对原生 Record 使用有容量的直接遍历，命名容器仍走原校验路径；模板引用复用有序目标切片。4096 AP 夹具的证据复制分配约降 72%，详见 [基准说明](../benchmarks.md)。
- 移除依赖源码快照、恢复脚本和失效实施记录；AGENTS、架构与验证文档纳入跟踪，架构门禁覆盖嵌套包及隐藏反向依赖。

固定正式 Connector v0.5.0、Expect v0.4.2，GOWORK=off 构建，无 replace。迁移见 [核心 API](../core-api.md)、[传输 API](../transport-api.md) 和 [架构迁移表](../architecture.md)。不自动重放、重连、回滚或保存配置。

发行包复用同提交 CI 的不可变制品，覆盖 Linux/macOS × amd64/arm64，并附源码、版本/提交、完整许可、MANIFEST.json 和 SHA256SUMS；不代表真实设备验收。
