# v0.4.0

本版本升级正式模块依赖，并适配 Connector 的类型化清单缓存模式。最低 Go 版本保持 1.26。

- Connector 升级至 v0.6.0，Expect 升级至 v0.5.0；pflag、YAML、x/sys 和 pgx 同步更新。
- 清单缓存模式使用 `netdisco.CacheMode`，配置值仍为 `prefer`、`refresh`、`only`。
- **配置迁移**：共享配置中的旧 TFTP 源文件键改为 `tftp.source_files.<平台>`，详见[兼容说明](https://github.com/gatework/go-wireless/blob/v0.4.0/docs/compatibility.md)。旧键会在设备连接前报错。

发行包复用同提交成功 CI 的不可变制品，覆盖 Linux/macOS × amd64/arm64，并附源码、完整许可和 SHA256SUMS。自动化验证不代表真实设备验收。
